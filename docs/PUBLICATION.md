# 公開用コピーの運用方針

このフォルダーは制作実績としてソース閲覧とローカル動作確認を行うコピーです。元の開発プロジェクトと分けて管理します。公開リポジトリは [nbtns/MBTIFriends_Public](https://github.com/nbtns/MBTIFriends_Public) です。

## 公開前に守ること

- 開発履歴や過去のコミットを持ち込まない。
- 本番用設定、秘密情報、APIキー、トークン、パスワード、署名用ファイルを含めない。
- 実在する人物の画像、個人情報、バックアップ、実データを含めない。デモデータは架空の人物だけにする。
- ライセンスはユーザーの指定に従う。未選択の場合は、利用許諾や再配布条件を独自に追加しない。

## CI

Semgrep、Gitleaks、品質チェックの3つのワークフローを同梱しています。各チェックの最新結果は [GitHub Actions](https://github.com/nbtns/MBTIFriends_Public/actions) で確認できます。

## 共有リンクの公開先

未設定時はブラウザーの現在のoriginに `/open` を付けたURLを使います。別の公開先を使う場合は、ビルド時に `VITE_PUBLIC_SHARE_BASE` へHTTPSの `/open` URLを設定し、ビルドを再実行してください。この設定値は共有リンクの基点として使うURLです。

ネイティブ環境で公開先を特定できない場合は `https://example.com/open` にフォールバックします。これは見本のURLで、実際の共有先として動作しません。自分のドメインでiOS Universal Linksを使う場合は、iOSのAssociated Domains entitlementもそのドメインに合わせて更新します。

共有カードのデータはURL fragmentに平文で含まれ、暗号化されません。実在する人の情報で共有リンクを作らないでください。

## ライセンス

ライセンスは未選択です。ユーザーが選ぶまで、利用・改変・再配布の許可を追加しません。
